## 🔥 Short description
A simple and user-friendly Restaurant Management web application for viewing menu items, placing orders, and managing restaurant operations. This project is built for learning & demonstration purpose and includes features like menu display, order creation, and a basic admin interface (if implemented).

---

## 🧩 Key Features
- Menu listing (categories, product cards with price & image).
- Add to cart & checkout flow (client-side).
- Order summary and basic order management.
- Responsive UI for desktop and mobile.
- Deployed to Firebase Hosting.
